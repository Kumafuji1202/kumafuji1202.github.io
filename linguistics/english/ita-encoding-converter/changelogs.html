Changelog

  1. 1.3.0 (2026 Aug 7th)

    • Added “Copy text” button
    • Changed UI layout for widescreen
    • Changed apparence of options for letterforms
    • Options now hidden by default in narrowscreen

  2. 1.3.1 (2026 Aug 29th)

    • Fixed left half of widescreen layout becoming too thin when input text contain long lines

  3. 1.4.0 (2026 Sep 8th)

    • Added “Catrinity 2.25+” encoding, following Catrinity’s release of version 2.25 on 2026 Sep 5th
    • Renamed “Catrinity” encoding to “Catrinity 2.18–2.24”

  4. 1.4.1 (2026 Sep 17th)

    • Renamed “Unicode proposal” encoding to “Unicode”, following Unicode 18.0’s release
    • Fixed the “copy text” button converting newlines, <, > and & in the output into <br>, &lt;, &gt; and &amp;

  5. 1.4.2 (2026 Nov 4th)

    • Added an “about” page and a changelog page
    • Made a little change to the encoding comparison table
    • Fixed the variable UI layout not working correctly as intended (the layout for widescreen being used for tall viewports when the resolution is high enough, CSS not being assigned at viewport width of 700px)

  6. 1.4.3 (2026 Nov 13th)

    • Added an option to use a variant of the Unicode 18.0 encoding where U+AB3C LATIN SMALL LETTER ENG WITH CROSSED-TAIL is used as the codepoint for the letter ing
    • Changed the order of letters in the encoding comparison table
